# Help {#top}

## Overview

**Purpose.** The User Guide is the step-by-step help built into PathScribe. This article explains how to find your way around it: the contents, the search box, the Help button on each screen, the F1 key, the "You are here" trail, the previous and next steps, the related actions, and the separate Administrator Guide for configuration screens.

**Intended users.** Everyone who signs in to PathScribe.

**Where it fits.** The guide opens in its own browser tab, so the work you have open on the screen stays where it is. You can use it before you start a task, or while you do one. You must be signed in to open it.

!!! note "English only for now, and still in draft"
    The guide is written in English. If PathScribe is set to another language, a note at the top of every guide page says "The User Guide is available in English only for now." Pages not yet reviewed carry the note "This article is a draft and is still being reviewed." Check a step against the screen in front of you before relying on it.

## Screen Tour

![The User Guide with the contents on the left and an article open](capture:help-overview)

The guide has two parts side by side. On the left is a narrow column with the guide title, a search box and the contents. On the right is the page: the contents page, or one article.

### Field definitions

**Left column**

| Item | What it means |
|---|---|
| User Guide (title) | A link to the contents page. |
| Search the User Guide | A search box. The grey text reads "Search the guide, for example: print a label". |
| Contents | The modules of PathScribe, in groups. A group's name opens that module's own page; the screens under it open their articles. The article you are reading is marked. |
| Search results | While you type, the contents are replaced by matching articles. "No articles match." appears if there are none. |

**The contents page** (`/help`)

| Item | What it means |
|---|---|
| Heading and introduction | "Step-by-step help for the work you do in PathScribe. Choose a screen, or search." |
| Module headings | Each module, with its screens listed beneath and the stage of work each belongs to (for example "Specimen Intake"). |

**An article**

| Item | What it means |
|---|---|
| You are here | A trail showing where you are: the guide, then the module, then the screen. Select an earlier part of the trail to go back up. |
| Workflow and For | The part of the work the article belongs to, and the roles it is written for. |
| Draft note | Shown on articles not yet reviewed. |
| Article text | Overview, Screen Tour, Step-by-Step Procedures, Tips and Best Practices, Related Features and Troubleshooting. Pictures are screenshots of the screen being described. |
| Previous step and Next step | Links at the bottom to the article that comes before and after in the usual order of work. They appear only where the article has one. |
| Related actions | A list of other articles connected to this one. |
| "This help page was not found." | Shown when the address does not match an article. "Choose a topic from the contents." follows. |

### Toolbar

| Button | What it does |
|---|---|
| Help (round **?** button in the top bar, beside the microphone) | Opens the User Guide article for the screen you are on, in a separate window that remembers where you put it. If your browser refuses a separate window, it opens a new tab instead. Its tooltip reads "Open the User Guide page for this screen". |
| Administrator Guide button (open book, in the top bar next to the Help button; on a configuration screen it sits at the top of the page) | Opens the Administrator Guide at that screen's section, in its own window or, if refused, a new tab. It appears only on screens that have such a section. Its tooltip reads "Open this screen's section of the Administrator Guide". |
| Name button at the top right | Opens your profile card. It has **User Guide** and **Administrator Guide** buttons (see the note below). |

### Icons and status indicators

| Indicator | Meaning |
|---|---|
| Round **?** mark | The Help button. |
| Arrow left (Previous step) and arrow right (Next step) | Moves along the usual order of work. |
| Marked item in the contents | The article you are reading. |

### Hotkeys

| Key | Action |
|---|---|
| F1 | View System Help: opens the User Guide article for the current screen in the same separate window as the Help button (a new tab if refused). If no article covers the screen, the contents page opens instead. |

The spoken commands "view help", "open help", "system help", "show help" and "help" do the same. On the report screen, Alt+V is Full View, so use the Help button there.

## Step-by-Step Procedures

### Standard workflow

**Open help for the screen you are on**

1. Look for the round **?** Help button in the top bar, beside the microphone, or press F1.
2. A separate window opens on the article for that screen, and reopens in the same place next time. If your browser refuses a window, a new tab opens instead. The screen you were working in is unchanged.
3. Read the Overview, then the Standard workflow under Step-by-Step Procedures.
4. Close the guide window, or switch back to PathScribe, when you have what you need.

**Find an article by searching**

1. Open the guide (F1 on any screen, or the address `/help`).
2. Select the search box and type what you want, for example `print label` or `amend report`. Every word you type must appear in the article.
3. The contents are replaced by the matching articles, best matches first (up to twelve).
4. Select an article. Clear the box to see the contents again.

**Move through the workflow**

1. At the bottom of an article, select **Next step** to read what usually comes next, or **Previous step** for what came before.
2. Use **Related actions** for other articles on the same subject.
3. Use the **You are here** trail to go up to the module's own page.

### Alternative workflow

1. From the contents page, choose a module and then a screen.
2. A link inside an article that names another article opens it in the same tab.
3. For configuration screens (the setup screens administrators use), use the Help button that opens the Administrator Guide. That guide has the full detail of every setting. The User Guide has no article for those screens.

### Exception handling

1. **A screen has no Help button.** No article covers that screen yet. Press F1 to reach the contents, or search.
2. **Two Help buttons appear on one screen.** The round **?** is the User Guide; the open book is the Administrator Guide. Hover to see the tooltip.
3. **The guide is not in your language.** It is English only for now; the PathScribe screens are in your language.

### Error recovery

1. If "This help page was not found." appears, choose a topic from the contents or use the search box.
2. If the guide stays on "Loading...", refresh the page. If it still fails, tell your laboratory manager.
3. If the new tab is blocked, allow popups for PathScribe, or open the address `/help` yourself.

## Tips and Best Practices

### Common mistakes

- Closing PathScribe's own tab instead of the guide tab.
- Using the guide as the last word. A Draft article describes the screen as it works today but has not yet been reviewed by your laboratory.
- Searching for a word that is only on the screen (a patient's name or accession number). The search covers the guide's text only.

### Efficiency recommendations

- Press F1 instead of searching; it opens the right article straight away.
- Keep the guide in a second window beside PathScribe while learning a new screen.
- Type two or three key words in the search box. All of them must match.

### Workflow recommendations

- Read the Overview and the Standard workflow before a first shift on a new screen.
- Use **Next step** during training to follow a case from intake to sign-out.

!!! note "The profile card's User Guide button"
    The name button at the top right opens a profile card with **User Guide** and **Administrator Guide** buttons. These open the older guide documents supplied with the installation, not the pages described in this article. For help on the screen you are using, use the Help button or F1.

## Troubleshooting

### Common user issues

| Problem | Likely cause |
|---|---|
| F1 opens the contents, not an article | No article covers the current screen. |
| The Help button is missing | No article covers the screen. |
| An article is in English while the screen is in French | The guide is English only for now. |
| The guide asks me to sign in | Your session ended. Sign in again. |
| A step does not match my screen | The article is a draft, or your laboratory has changed a setting. Tell your laboratory manager. |

### Resolution steps

1. Select the PathScribe page and press F1 again.
2. Search the guide for the task.
3. Open `/help` and browse the contents.
4. Refresh the page.

### When to contact support

Contact your laboratory's PathScribe support when an article is wrong, a link inside it goes nowhere, or the guide will not load. Have the article title and the time of the problem ready.
