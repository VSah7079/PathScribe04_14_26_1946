    # 2단계: 마스터 사전 및 임상 기초 데이터 (두 번째로 설정)

    2단계는 검사실의 일상 업무에서 선택해 사용하는 목록의 집합입니다. 부서, 검체 유형, 염색, 프로토콜, 용기, 카세트 색상, 의사, 고객 서비스 수준, 그리고 보고서에 사용하는 코드 및 분류 목록이 여기에 속합니다. 이 목록 중 단독으로 작동하는 것은 없습니다. 검체 유형은 부서, 세부 전문 분야, 프로토콜을 가리킵니다. 카세트 규칙은 프로토콜과 색상을 가리킵니다. 고객 서비스 수준은 고객 시설을 가리킵니다. 그래서 2단계는 1단계(2장의 시설, 인원, 장치) 다음에 오며, 자체 순서가 있습니다.

    2단계는 아래 순서대로 설정하십시오. 각 화면에는 같은 정보를 담은 설정 순서 상자가 있으며, 빌더는 어떤 화면도 자신보다 뒤에 오는 화면을 필요로 하지 않는지 확인합니다.

    1. 관리 기관: 표준 기관과 그 보존 기간 수치. ForMedrixAI 내부 전용입니다.
    2. 코드 체계: 국가별로 진단 코드 체계가 꺼짐, 선택, 필수 중 어느 상태인지, 그리고 보유한 라이선스.
    3. 용어 서비스: 코드 검색 서비스의 상태 점검.
    4. 코드 일괄 가져오기: 청구 코드의 CSV 가져오기.
    5. 부서: 접수 시 검체의 대분류.
    6. 세부 전문분야: 병리 작업 그룹과 그 라우팅.
    7. 진단 카탈로그: 염색, 항체, 분자 검사, 절단 프로토콜, 빠른 오더 매크로.
    8. 프로토콜 사전: 검체의 처리 워크플로.
    9. 용기 유형: 검체가 도착하는 용기.
    10. 검체 사전: 위의 목록들을 서로 연결하는 검체 유형.
    11. 플래그: 케이스 및 검체 플래그.
    12. 자산 위치 사전: 이름이 붙은 물리적 위치와 영안실 보관 칸.
    13. 콜드체인: 보관 장치, 조건 유형, 온도 측정값.
    14. 검체 결함: 결함 유형과 해결 유형.
    15. 장기 지도: 해부학적 지도의 색상, 패턴, 질문 연결.
    16. 카세트 색상: 색상 사전.
    17. 카세트 라우팅 규칙: 카세트에 어떤 색상을 부여하는지.
    18. 잉크 색상: 절제연 잉크 색상.
    19. 시약 및 용액 로트: 시약의 로트, 유효 기간, QC 상태.
    20. 의사: 오더 의사와 검체 제출 의사.
    21. 시설 구성: 고객 계정(시설 사전과 같은 화면).
    22. 고객별 서비스 수준: 고객별 처리 시간 약속.
    23. 비정상 트리거 규칙: 케이스에 플래그를 붙이는 필드와 값의 쌍.
    24. 세포병리 탭: 세포병리 설정의 시작 페이지.
    25. 명명 체계: 세포병리가 사용하는 보고 체계.
    26. 판독 및 권고: 세포병리 범주 목록.
    27. 비부인과 분류 (밀라노/파리): 침샘 및 요로 범주.
    28. 검진 전략: 병용 검사 또는 HPV 우선, 재검 기간.
    29. 비부인과 라우팅: 비부인과 케이스가 가는 작업 목록.
    30. 국가 및 검사실 규칙: 업무량 상한, 되돌아보기, 긴급 서명, 검진 간격.
    31. 보조 기기 판독: 전체 슬라이드 영상 또는 전통적 판독.
    32. 세포-조직 상관관계 (SNOMED): 상관 검토에 사용하는 SNOMED 중증도 순위.

    아래 부분은 설정 순서가 아니라 주제를 따릅니다. A부는 해부병리 전문 분야, B부는 검체와 조직, C부는 용기, 카세트, 잉크, D부는 염색과 프로토콜, E부는 코드 라이브러리, F부는 의사, 고객, 관리 기관입니다.

    상태 표기. 각 화면에는 작성 표준의 다섯 가지 상태 표기 중 하나가 표시됩니다. 구현됨, 데모, 부분 구현, 예정, 미구현입니다. 이 장의 거의 모든 사전에는 운영 서비스와 문서화된 API 계약이 있으므로 대부분 구현됨입니다. 예외는 화면에 명시되어 있습니다. 장기 지도 설정과 코드 체계 정책은 브라우저에만 보관되며, 콜드체인 측정값은 모의 값입니다.

    모든 사전 화면의 공통 사항. - 변경하려면 해당 화면 고유의 config:...:manage 권한이 필요합니다. 권한이 없으면 화면을 열어 데이터를 볼 수는 있지만 조작 항목은 회색으로 비활성화됩니다. 이 장의 권한은 높은 위험으로 표시되어 있으므로, 허용되었든 거부되었든 모든 확인이 감사 로그에 기록됩니다. - 여기 있는 대부분의 사전은 수행 검사실별로, 또는 전체(모든 검사실)에 대해 관리됩니다. 이름이나 코드는 한 검사실 안에서, 또는 전체 안에서 고유해야 합니다. - 대부분의 목록은 삭제를 지원하지 않습니다. 행을 비활성으로 바꾸며, 이미 그 행을 사용하는 모든 기록은 유지됩니다. - 오더에서 들어온 이름이나 코드가 어떤 항목과도 일치하지 않으면 미확인 행이 만들어집니다(부서, 의사, 자산 위치, 시설이 이렇게 동작합니다). 이 행은 사용할 수 있지만 누군가 확인한 뒤 확인을 선택해야 합니다.

    # A부: 해부병리 전문 분야

    홈 › 구성

    이 부분은 검사실의 부서와 작업 그룹을 설정하는 화면과 세포병리 탭을 다룹니다. PathScribe에는 "전문 분야" 화면이 하나 있는 것이 아닙니다. 해부병리의 다섯 가지 전문 분야는 여기에 나열된 여러 화면을 통해 설정하므로, 표에서 각 분야별로 무엇이 있고 무엇이 없는지 설명합니다.

    전문 분야 현재 구성할 수 있는 것 존재하지 않는 것
    수술병리 수술 조직 부서와 그 기본 그로싱 템플릿, 검체 사전의 SURGICAL_TISSUE 검체 범주, 장기 지도, B부부터 D부까지의 프로토콜 및 카세트 사전. 별도의 "수술병리" 설정 화면.
    세포병리 체액 / 세포병리 부서, GYN_CYTOLOGY 및 NON_GYN_CYTOLOGY 검체 범주, 세포병리 탭 전체(이 장의 화면 8개와 4장 및 8장의 화면 4개). 없음. 자체 설정 탭이 있는 유일한 전문 분야입니다.
    피부병리 피부병리라는 이름의 세부 전문분야(기본 제공)와 피부 관련 키워드를 그곳으로 보내는 기본 제공 케이스 라우팅 규칙. Mohs 현미경 수술 단계 지도는 장기 지도에 포함됩니다. 피부병리 부서, 검체 범주 또는 설정 화면.
    혈액병리 혈액병리라는 이름의 세부 전문분야(기본 제공)와 혈액학 관련 키워드를 그곳으로 보내는 기본 제공 케이스 라우팅 규칙. 혈액병리 부서, 검체 범주 또는 설정 화면.
    부검 검체 사전의 AUTOPSY 검체 범주, 자산 위치 사전의 영안실 보관 칸과 점유 현황 보기, 프로토콜 사전의 부검 절단 프로토콜, AUTOPSY 워크스테이션 그룹 분야(워크스테이션 그룹), TAT 구성 탭의 AUTOPSY_PAD 및 AUTOPSY_FAD 처리 시간 목표 유형. 부검 탭 또는 부검 전용 유지 관리 화면.

    이 세부 전문 분야를 사용하는 기본 제공 케이스 라우팅 규칙은 라우팅 규칙(4장)에 있습니다.

    # 부서

    홈 › 구성 › 시스템 › 임상 조회 › 부서

    상태: 구현됨

    1. 탐색 경로: 설정 탭 시스템 > 그룹 임상 조회 2. 관리 항목: 부서

    3. 업무 목적 및 범위. 부서는 접수 시 검체의 대분류입니다. 예를 들어 수술 조직, 체액 / 세포병리, 조직 전용 / 의뢰 검사가 있습니다. 부서는 케이스가 어떤 그로싱 템플릿으로 시작하는지, 부서가 관할권 기본값과 다른 기간 동안 기록을 보존하는지, 그리고 보고서 머리글에 어떤 검사실장과 인증 번호가 인쇄되는지를 결정합니다. 편집 창의 케이스 마스크 링크를 누르면 케이스 마스크 구성으로 이동하며, 그곳에서 부서의 접수번호 마스크를 설정합니다.

    4. 사전 요건 및 의존 관계. 보존 재정의는 현재 관할권에 대해 관리 기관에서 설정한 하한과 대조하여 확인됩니다. 관할권에 보존 수치를 가진 기관이 없으면 대조할 하한이 없습니다. 그로싱 템플릿 목록은 제품에 고정되어 있으므로(선택지 3개) 다른 화면에 의존하지 않습니다. 부서는 검체 사전(각 검체 유형이 부서를 지정함), 프로토콜 사전(체액 부서의 새 프로토콜은 따라붓기 트랙으로 시작함), 그리고 존재하지 않는 부서를 지정한 오더가 들어오면 미확인 부서를 만드는 오더 접수 기능이 읽습니다.
