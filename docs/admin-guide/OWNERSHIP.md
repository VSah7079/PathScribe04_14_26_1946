# Who documents which screen (Batch 646)

Every screen has one canonical id (`screen-<name>`) and exactly one owning chapter. Chapter N documents Tier N-1 (Chapter 2 = Tier 1 ... Chapter 8 = Tier 7). Link to a screen owned by another chapter with its canonical id; write only the screens you own. A screen found in the app that is not listed goes in the nearest chapter and is noted in `OPEN_QUESTIONS.md`.

Canonical id rule: `screen-` + capture id, with a leading `system-`, `cytology-` or `screen-` removed. Capture id is what the screenshot placeholder uses.
