# Translation review register

PathScribe's French, German, Dutch and Korean text is machine-translated using standard laboratory terminology (CLAUDE.md, rule 3). **Before clinical use, a native speaker with laboratory or pathology background should review it.** Korean clinical wording is the priority: it has had the least review. This register lists the strings waiting for review, so a reviewer has one place to work from and the results are recorded.

## How to review

1. Work through the rows below by **Priority**. High means clinical or patient-safety wording: critical findings, correlation windows, decants and billing, accession answers.
2. Check each translation against the English. In particular:
    * Is it the term a pathology lab in that country actually uses (e.g. "décanteur", "Dekant", "디캔트" for a decant)?
    * Is the register formal enough for a clinical system?
    * Do the `{{placeholders}}` still read naturally in the sentence?
3. Write any correction in the row, and set **Review** to `OK`, `Changed` or `Query`, with your initials and the date.
4. A developer applies the changes to `src/i18n/locales/<lang>.json`. `localeParity.test.ts` checks that keys and placeholders still match.

Belgian French and Belgian Dutch (`fr-BE`, `nl-BE`) fall back to `fr` and `nl`. None of these strings uses a word Belgium says differently.
