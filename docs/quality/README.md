# docs/quality

Quality and review records for PathScribe.

- [`QA_AND_TESTING.md`](QA_AND_TESTING.md): how PathScribe is tested.
- [`TRANSLATION_REVIEW.md`](TRANSLATION_REVIEW.md) (Batch 453): the register for native-speaker review of the French, German, Dutch and Korean UI text.
  - The fr/de/nl/ko text is machine translation using standard lab terminology. Clinical wording, Korean especially, needs a native speaker before clinical use.
  - The register lists each string with its batch, priority and all five languages, and records the reviewer and the outcome.
  - It starts with the 63 strings from Batches 452 and 453. Korean flags from earlier batches are in their entries in [`src/i18n/README.md`](../../src/i18n/README.md).
