# Voice phrases to review (French, German, Dutch, Korean, Spanish)

Regenerated Oct 24, 2026 (Batch 666) from the live action registry, and it now replaces the per-batch tables that were appended after Batch 614. **None of these phrases has been reviewed by a native speaker.** They were written by machine, to standard laboratory wording, and the English column is the source. This list exists so a reviewer can work through them in one place; it does not claim a review has happened. Korean clinical wording in particular should be checked by a native speaker before clinical use. Spanish is Castilian, formal register (usted).

How to use it: a reviewer marks each row right, change, or remove. Changes go into `voiceTriggersByLanguage` for the command (the seed file for its screen under `src/services/actionRegistry/`, Spanish in `spanishVoiceTriggers.ts`, and the Report Draft commands in `src/services/voice/reportDraftVoiceActions.ts`, which are not in the stored command list). Two commands on one screen, or two always-on commands, must not share a phrase in any language (the guard in `actionsCoverage.guard.test.ts` fails if they do), and a phrase a screen command shares with an always-on one must be on the known list in that test.

Hotkeys are not translated, so they are not on this list. The Role Dictionary labels are in the locale files and are covered by the locale review workbooks (`docs/quality/TRANSLATION_REVIEW.md`).
